# The ROM is still the game

Write-up of a Landstalker (Mega Drive, 1992) remaster: the unmodified ROM runs in
Genesis Plus GX as the authoritative simulation, a bridge reads its work RAM at
60Hz, and a three.js renderer draws the world as real geometry from assets
extracted out of the cartridge.

Read it at **https://dmahlow.github.io/landstalker-writeup/**

- `index.md` - the article
- `media/` - screenshots, comparisons and clips

No ROM, no extracted game assets, and no code in this repo. Ship code, never content.
